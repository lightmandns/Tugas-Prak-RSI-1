# Git dan Github
Git adalah sistem versi kontrol atau version control system yang berfungsi untuk melacak perubahan pada kode yang kita buat. Sementara GitHub adalah platform berbasis cloud yang memungkinkan kita menyimpan dan berbagi kode yang kita buat menggunakan Git.
